# Enquadra+ v0.2.0-alpha.7

Sétima prévia da v0.2, com revisão visual administrativa.

## Principais mudanças

- Remove tons padrão rosados/salmão herdados de papéis não definidos do Material 3.
- Fecha a paleta completa do app em azul institucional e cinzas frios.
- Estados selecionados passam a usar azul claro acinzentado.
- Containers secundários e terciários passam a tons administrativos neutros.
- Mantém os novos seletores tonais, badges, checklists e seletor pesquisável introduzidos após a alpha.6.
- Mantém a reorganização funcional de Infrações, Normas e Ferramentas e o hotfix de inicialização.

## Direção visual

A interface passa a priorizar aparência técnica e institucional: azul-marinho, azul acinzentado, superfícies brancas/cinza-claro e contraste discreto. Nenhum papel visual do tema deve cair nos tons padrão rosa/salmão do Material.

## APK

O APK anexado é um debug APK de pré-release para testes. Ele é compilado pelo workflow controlado a partir do commit-alvo validado.
