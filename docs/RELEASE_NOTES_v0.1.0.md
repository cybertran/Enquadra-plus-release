# Enquadra+ v0.1.0

Primeira versão funcional da base do Enquadra+.

## Destaques

- Projeto Android em Kotlin + Jetpack Compose.
- Material Design 3.
- Estrutura local-first com Room.
- Pesquisa offline por código, artigo, descrição e palavra-chave.
- Primeira ficha oficial do MBFT: código 682-32, art. 231, IV.
- Tela de detalhes com gravidade, pontuação, infrator, competência, constatação, penalidade e medida administrativa.
- Seções de quando autuar, quando não autuar, definições e procedimentos.
- Exemplo oficial do campo de observações do AIT.
- Rastreabilidade da fonte oficial usada em cada ficha.
- Estrutura inicial de relações entre enquadramentos.
- Base preparada para expansão com importação das demais fichas do MBFT.

## Fonte dos dados

Os dados normativos do Enquadra+ são obtidos diretamente de fontes oficiais, como CTB, MBFT, Resoluções CONTRAN e atos da Senatran.

Esta versão não incorpora análises jurídicas, comentários, resumos de jurisprudência ou conteúdo autoral de terceiros.

## Observação sobre build

O workflow do GitHub Actions foi desativado como gatilho automático porque a cota de Actions do repositório está esgotada. Esta versão representa a base de código v0.1.0; a geração e validação do APK deve ser feita localmente ou quando houver runner disponível.
