# Enquadra+ v0.2.0-alpha.8

Oitava prévia da v0.2, com melhoria de clareza na tela de atualizações jurídicas.

## Principais mudanças

- Diferencia claramente os estados de verificação:
  - Verificando…
  - Nenhuma atualização disponível
  - Não foi possível verificar
  - Erro durante a verificação
  - Atualização disponível
  - Base atual preservada
- Adiciona mensagens explicativas para deixar claro quando:
  - a fonte oficial ainda está sendo consultada;
  - nenhuma atualização foi encontrada;
  - a fonte oficial não pôde ser consultada;
  - houve falha antes do fim da verificação.
- Mantém a paleta administrativa em azul institucional e cinzas frios.
- Mantém os seletores, pills, badges e checklists modernizados.

## APK

O APK anexado é um debug APK de pré-release para testes, compilado pelo workflow controlado a partir do commit-alvo validado.
